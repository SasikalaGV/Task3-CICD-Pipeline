Project Details

A basic CI/CD pipeline for a web application.

Pipeline stages and tools

One tool is used for each stage of the pipeline.

StageToolPurpose
1. Source code managementGit & GitHubVersion control with branches, pull requests and releases
2. Automated build & testGitHub ActionsBuilds and tests the website on every push
3. Static analysis & securityTrivyScans files and images for vulnerabilities
4. ContainerisationDockerPackages the website as a container image
5. DeploymentKubernetes (Minikube)Runs the container in a cluster
6. Monitoring & loggingPrometheusCollects metrics and raises alerts
