Why this project?

Modern software teams use CI/CD pipelines to deliver features quickly and safely. This website is deliberately simple so the focus stays on the pipeline that builds, tests, scans, packages, deploys and monitors it automatically.

Every change pushed to GitHub goes through the same automated steps, so the result is repeatable and every step leaves evidence.

What I learned

  • Using Git branches, pull requests and releases
  • Writing automated unit and integration tests
  • Finding vulnerabilities with security scanners
  • Packaging an app with Docker and running it on Kubernetes
  • Describing infrastructure as code with Terraform
  • Monitoring an app with Prometheus and Grafana
